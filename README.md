## Patterns covered

```
Creational          Structural          Behavioral
──────────          ──────────          ──────────
Singleton           Adapter             Observer
Factory             Decorator           Strategy

```

## UML diagram types

```
Class diagram         → structure of classes and relationships
Sequence diagram      → object interactions over time
Use case diagram      → system functionality from a user perspective
```
